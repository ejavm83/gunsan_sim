# 용어 및 약어

사이드바 슬라이더, 개요/공정/방법론 탭, 실행 후 KPI/차트에 쓰이는 표현을 정리했습니다.  
이 파일은 웹의 용어 및 약어 페이지에서 바로 편집/저장할 수 있습니다.

## 약어

| 약어 | 설명 |
|------|------|
| SCR | South Wire Rod. 연속 주조로 만든 구리 봉/선재를 코일 형태로 권취한 제품 |
| DES | Discrete Event Simulation, 이산사건 시뮬레이션 |
| CP-SAT | Constraint Programming + SAT, OR-Tools 최적화 솔버 |
| SAT | Boolean Satisfiability(논리식 만족 문제) |
| KPI | Key Performance Indicator(핵심 성과 지표) |
| ROI | Return on Investment(투자 대비 효과) |
| CV | Coefficient of Variation(변동계수) |

## 공정/설비 용어

| 용어 | 설명 |
|------|------|
| 스크랩 | 재활용 구리 원료 |
| 계근대 | 입고/출하 차량 중량을 재는 자원 |
| 하역 베이 | 트럭 하역 작업 위치 |
| 선별 | 이물질 제거/등급 분류 단계 |
| 압착 | 스크랩을 블록화하는 프레스 공정 |
| 파레트 버퍼 | 장입 전 대기 저장소 |
| 반사로 | 용해로(Reverberatory furnace) |
| 장입 | 반사로에 원료를 투입하는 단계 |
| 용해 | 반사로에서 용탕을 만드는 단계 |
| 주조 | 용탕을 제품으로 생산하는 단계 |
| 야적장 | 완제품 임시 보관 장소 |
| 출하 | 상차 후 트럭 반출 단계 |
| 병목 | 전체 처리량을 제한하는 가장 느린 단계 |

## 모델/대시보드 용어

| 용어 | 설명 |
|------|------|
| SimPy | 이산사건 시뮬레이션 프레임워크 |
| 이벤트 로그 | 시뮬레이션 이벤트 기록(도착/배치 시작/완료 등) |
| 버퍼 | 공정 간 속도 차이를 흡수하는 저장소 |
| 블로킹 | 후행 버퍼 포화로 선행 공정이 정지되는 현상 |
| 가동률 | 자원 점유율 지표 |
| 처리량 | 단위 시간당 처리/생산량 |
| 체류시간 | 트럭 도착~출차 시간 |
| Gantt | 반사로 구간(장입/용해/주조) 시각화 차트 임|
